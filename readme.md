# Проект: Он тебе нужно

## Описание

Вёрстка по ТЗ. Применены технологии: HTML, CSS, JS. Для шаблона страницы использовались grid и flexbox.

## Демо
Опубликованная версия: **https://thekostvk.github.io/ono-tebe-nado/**

## Особенности

- Простой и понятный код
- Простая структура проекта
- БЭМ
- Grid 
- Flexbox
- Готов к подключению JS

## Требования

- Node.js (версия 14 или выше)
- npm (последняя версия)

---

## Установка и запуск

### Установка зависимостей
```bash
npm install
```
### Установка зависимостей
```bash 
npm install
```
### Запуск в режиме разработки
```bash 
npm run dev
```
### Сборка для продакшена
```bash 
npm build
```
